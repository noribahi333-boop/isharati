# إشارتي

نسخة أولية لتطبيق مجتمعي خاص بفئة الصم والبكم في الدول العربية.

## المرحلة الحالية
- شاشة رئيسية (منشورات: نص / صورة / فيديو) مع إعجاب وتعليقات
- شاشة نشر منشور جديد
- شاشة الملف الشخصي (تعرض منشوراتك)

هذه واجهات تجريبية أولية (Prototype) لتجربة الشكل العام، وليست متصلة بأي حساب حقيقي أو خادم أو تخزين حتى الآن.

## الخطوة التالية
- ربط حسابات حقيقية (تسجيل دخول)
- رفع فيديوهات/صور حقيقية وتخزينها
- تصنيف المنشورات حسب الدولة أو اللهجة الإشارية
- إشعارات بصرية بدل الصوتية

## كيف تحصل على ملف APK لتجربته على هاتفك
شوف ملف `BUILD_ANDROID.md` — فيه طريقتان جاهزتان بدون ما تكتب أي كود بنفسك.
